# make.fun ai-joke-03 entry

A Python program that writes one original one-liner about AI coding
agents to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The joke: "My coding agent imported a library that doesn't exist, then
wrote it, then deprecated it."

Standard library only. No network. Both runs write identical bytes.

Run it: `MAKEFUN_OUTPUT_DIR=out python3 main.py`
